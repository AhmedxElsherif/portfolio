    GitHub connection

    The dashboard publishes changes by committing data/site.json and uploaded files (images, 3D models) directly to your repository through the GitHub API. Your token is stored only in this browser.

    How to create the token
    1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories → choose your portfolio repo.
    3. Permissions → Repository permissions → Contents: Read and write.
    4. Copy the token and paste it above. Never commit it to the repo.

    3D model tips

    • Best format: GLB. In KiCad PCB Editor use File → Export → GLB (KiCad 8+). Older versions: File → Export → VRML (.wrl), which is also supported.
    • Also supported: .gltf, .stl, .obj (e.g. enclosures from SolidWorks/Fusion).
    • GitHub Pages does not serve Git LFS files, and uploads through the API should stay under ~25 MB. Compress large boards with npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt (Draco/Meshopt are supported).
    • If the board appears standing up, set rotation X to -90 in the model row.
